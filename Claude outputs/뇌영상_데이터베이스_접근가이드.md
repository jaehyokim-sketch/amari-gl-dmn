## 2. 데이터베이스별 접근 방법 (단계별)

### 2.1 HCP (Human Connectome Project) — 최우선 권장

**URL**: https://www.humanconnectome.org  
**특징**: 건강한 성인 1,200명+의 고해상도 MRI/fMRI/dMRI, DMN 연구에 최적  
**하위 프로젝트**:
- Young Adult HCP: 22–35세, 7T fMRI 포함
- Lifespan HCP: 전 생애주기 뇌 변화
- Connectomes Related to Human Disease: 신경정신과 질환 포함

**접근 절차**:
1. https://db.humanconnectome.org 접속
2. "Register" → 연구자 계정 생성
3. Data Use Terms (DUT) 동의
4. 데이터 탐색: "WU-Minn HCP Dataset" 선택
5. Amazon S3 or Aspera 다운로드 (ConnectomeDB 내장)

**데이터 다운로드 도구**:
```bash
# Aspera CLI 설치 (권장, 고속)
pip install ibm-aspera-connect

# 또는 ConnectomeDB에서 GUI로 직접 다운로드
# 형식: NIfTI (.nii.gz), HCP-format cifti (.dtseries.nii)
```

### 2.2 OpenNeuro — 가장 빠른 접근

**URL**: https://openneuro.org  
**특징**: 35,000+ 참여자, 900+ 공개 데이터셋, 즉시 다운로드 가능  
**데이터 형식**: BIDS (Brain Imaging Data Structure) 표준

**접근 절차**:
1. https://openneuro.org 접속
2. Google 계정으로 로그인 (별도 심사 없음)
3. Browse by Modality → "MRI" 선택
4. Task/Diagnosis 필터로 resting-state 데이터셋 검색
5. 직접 다운로드 또는 DataLad/OpenNeuro CLI 사용

**CLI 다운로드**:
```bash
# OpenNeuro CLI 설치
pip install openneuro-py

# 데이터셋 다운로드 예시 (1000FCP resting-state)
openneuro download --dataset ds000030 --include "sub-*/func/*rest*"
```

### 2.3 ADNI (Alzheimer's Disease Neuroimaging Initiative)

**URL**: https://adni.loni.usc.edu  
**특징**: 2,000+ 참여자, 알츠하이머 + 정상 대조군, T1/DTI/PET  
**데이터 형식**: DICOM (→ dcm2niix로 NIfTI 변환 필요)

**접근 절차**:
1. https://adni.loni.usc.edu 접속
2. "Apply for Data Access" 클릭
3. 연구자 정보 + 소속기관 입력
4. ADNI Data Sharing Agreement 서명
5. 관리자 승인 후 LONI IDA 접근 권한 부여
6. https://ida.loni.usc.edu 에서 데이터 검색 및 다운로드

**중요**: 승인까지 수일~수주 소요. 비상업적 연구 무료.

### 2.5 NACC (National Alzheimer's Coordinating Center)

**URL**: https://naccdata.org  
**특징**: 29,000+ 참여자, T1/T2/DTI/FLAIR/PET  
**데이터 형식**: DICOM 또는 NIfTI

**접근 절차**:
1. https://naccdata.org 접속
2. "Request data" → "Create a NACC data request"
3. 연구 목적 및 계획 입력
4. 관리자 승인 후 이메일로 **Access Key ID + Secret Access Key** 수신
5. AWS CLI로 데이터 다운로드:

```bash
# AWS CLI 설치
pip install awscli

# 자격증명 설정 (이메일로 받은 키 사용)
aws configure
# AWS Access Key ID: [이메일 수신 키 입력]
# AWS Secret Access Key: [이메일 수신 비밀 키 입력]
# Default region: us-east-1

# 데이터 다운로드
aws s3 sync s3://naccdata/ ./nacc_data/ --request-payer requester
```

### 2.6 OASIS (Open Access Series of Imaging Studies)

**URL**: https://www.oasis-brains.org  
**하위 데이터셋**:
- OASIS-1: 416명 단면, CC BY (비상업적)
- OASIS-2: 150명 종단, CC BY (비상업적)  
- OASIS-3: **1,379명, 다모달(MRI+PET+fMRI)**, CC BY (비상업적) ← DMN 연구에 적합
- OASIS-4: 663명, 임상 데이터, CC BY-NC

**접근 절차 (OASIS-3 rs-fMRI)**:
1. https://www.oasis-brains.org 접속
2. "Get Started" → "DATASETS" 탭
3. "OASIS-3" 선택 → "Browse Data" 클릭
4. XNAT CENTRAL로 이동: https://central.xnat.org/
5. XNAT 계정 생성 (무료)
6. "OASIS3" 프로젝트 검색 및 접근 신청

```python
# XNAT Python API로 다운로드
pip install xnat

import xnat
with xnat.connect('https://central.xnat.org', user='USERNAME', password='PASSWORD') as session:
    project = session.projects['OASIS3']
    # rs-fMRI 세션 검색
    for subject in project.subjects.values():
        for experiment in subject.experiments.values():
            if 'func' in str(experiment):
                experiment.download('/path/to/output')
```

### 4.3 DMN 시드 기반 rsFC 분석

```python
import numpy as np
from nilearn import image, maskers, plotting
from nilearn.connectome import ConnectivityMeasure

# === 1. 데이터 로드 ===
fmri_img = image.load_img('sub-01_task-rest_space-MNI152NLin2009cAsym_res-2_desc-preproc_bold.nii.gz')
confounds = np.loadtxt('sub-01_task-rest_desc-confounds_timeseries.tsv', skiprows=1)

# === 2. DMN 핵심 노드 MNI 좌표 (시뮬레이션과 동일) ===
DMN_SEEDS = {
    'mPFC':  [0,   52,  -6],
    'PCC':   [0,  -56,  26],
    'L_AG':  [-46, -64,  28],
    'R_AG':  [46,  -64,  28],
    'L_MTG': [-60, -24, -12],
    'R_MTG': [60,  -24, -12],
}

# === 3. 시드 마스커 생성 ===
seed_masker = maskers.NiftiSpheresMasker(
    seeds=list(DMN_SEEDS.values()),
    radius=8,           # 8mm 구형 마스크
    detrend=True,
    standardize=True,
    low_pass=0.1,       # 저역통과 필터 (Hz)
    high_pass=0.01,     # 고역통과 필터 (Hz)
    t_r=2.0,            # TR (초) — 데이터에 맞게 조정
    memory='nilearn_cache'
)

# === 4. 시드 시계열 추출 ===
seed_time_series = seed_masker.fit_transform(fmri_img, confounds=confounds)
print(f"시드 시계열 shape: {seed_time_series.shape}")  # (timepoints, n_seeds)

# === 5. 전뇌 rsFC 계산 (mPFC 시드 기준) ===
brain_masker = maskers.NiftiMasker(
    smoothing_fwhm=6,
    detrend=True,
    standardize=True,
    low_pass=0.1,
    high_pass=0.01,
    t_r=2.0
)
brain_time_series = brain_masker.fit_transform(fmri_img, confounds=confounds)

# Pearson 상관 계산
mpfc_seed = seed_time_series[:, 0]  # mPFC 시계열
rsfc_map = np.array([
    np.corrcoef(mpfc_seed, brain_time_series[:, i])[0, 1]
    for i in range(brain_time_series.shape[1])
])
rsfc_img = brain_masker.inverse_transform(rsfc_map)

# === 6. DMN rsFC 행렬 계산 ===
correlation_measure = ConnectivityMeasure(kind='correlation')
rsfc_matrix = correlation_measure.fit_transform([seed_time_series])[0]

print("\nDMN 노드 간 rsFC 행렬:")
node_names = list(DMN_SEEDS.keys())
for i, name_i in enumerate(node_names):
    for j, name_j in enumerate(node_names):
        if i < j:
            print(f"  {name_i} — {name_j}: {rsfc_matrix[i,j]:.3f}")

# === 7. 시각화 ===
import matplotlib.pyplot as plt
import seaborn as sns

fig, axes = plt.subplots(1, 2, figsize=(14, 5))

# rsFC 행렬 히트맵
sns.heatmap(rsfc_matrix, annot=True, fmt='.2f',
            xticklabels=node_names, yticklabels=node_names,
            cmap='RdBu_r', center=0, vmin=-1, vmax=1,
            ax=axes[0])
axes[0].set_title('DMN 노드 간 rsFC 행렬')

# mPFC 시드 전뇌 rsFC 맵
plotting.plot_stat_map(rsfc_img, threshold=0.3,
                       title='mPFC 시드 기반 rsFC',
                       display_mode='ortho',
                       axes=axes[1])
plt.tight_layout()
plt.savefig('dmn_rsfc_analysis.png', dpi=150)
plt.show()
```

### 4.4 DMN-TPN 반상관 분석 (시뮬레이션 결과와 비교)

```python
# TPN 핵심 노드
TPN_SEEDS = {
    'L_dlPFC': [-40, 26, 34],
    'R_dlPFC': [40,  26, 34],
    'L_FEF':   [-26, -8, 50],
    'L_IPS':   [-26, -58, 50],
}

all_seeds = {**DMN_SEEDS, **TPN_SEEDS}
all_masker = maskers.NiftiSpheresMasker(
    seeds=list(all_seeds.values()),
    radius=8, detrend=True, standardize=True,
    low_pass=0.1, high_pass=0.01, t_r=2.0
)
all_ts = all_masker.fit_transform(fmri_img, confounds=confounds)
full_matrix = np.corrcoef(all_ts.T)

# DMN-TPN 반상관 확인
n_dmn = len(DMN_SEEDS)
dmn_tpn_block = full_matrix[:n_dmn, n_dmn:]
print(f"\nDMN-TPN 반상관 평균: {dmn_tpn_block.mean():.3f}")
print(f"  (시뮬레이션 예측: −0.2 ~ −0.4)")
print(f"  (Fox et al. 2005 실측: −0.45 ~ −0.15)")
```
