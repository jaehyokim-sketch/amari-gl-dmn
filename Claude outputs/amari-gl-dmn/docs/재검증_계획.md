## 0. 평가 의견의 코드 수준 확인

평가 의견을 받은 뒤 저장소 코드를 직접 대조했다. 5개 지적은 모두 사실로 확인되었고,
그중 두 가지는 **지적된 것보다 더 심각**하다.

### 0.1 확인된 사실

| 평가 지적 | 코드/문서상 확인 내용 | 판정 |
|---|---|---|
| ① 좌표계 불일치 | `세션기록_Session2.md:14` — "130명 중 **sform_code=1 제약으로** 13명" | **지적보다 심각** |
| ② raw BOLD 전처리 없음 | 저장소에 전처리 코드 없음. `nibabel`·`nilearn` 미설치 | 사실 |
| ③ SC 출처 혼재 | `src/connectivity.py:36-95` 전체가 **손으로 입력한 상수 리스트** | **지적보다 심각** |
| ④ β가 반상관을 만듦 | `PORTING_NOTES.md:86` — β는 균일 모드만 움직이는 랭크-1 섭동 | 사실 + 이론적 함의 |

### 0.2 ①이 더 심각한 이유 — 표본이 오류 기준으로 선택되었다

`sform_code=1` 은 NIfTI 규격에서 `NIFTI_XFORM_SCANNER_ANAT`, 즉 **affine이 복셀을
스캐너 좌표로 보낸다**는 표시다. MNI 공간이면 `sform_code=4`(`NIFTI_XFORM_MNI_152`)여야 한다.

즉 130명 중 13명을 남긴 그 필터는 **"MNI 공간이 아닌 피험자만 고르는" 필터**였다.
그 13명에 MNI 좌표 (0,52,−6) 등을 적용했으므로, 추출된 시계열이 mPFC라는 보장이 전혀 없다.

따라서 r=0.188 은 "raw 데이터의 한계"가 아니라 **해석 불가능한 값**이다.
논문 `#hcp` 섹션과 결론(`amari_gl_v7.html:700`)의 "방향 일치가 확인되었다"는 서술은
근거가 없으므로 **철회 대상**이다. 재분석 전까지 이 수치는 인용하지 않는다.

### 0.3 ③이 더 심각한 이유 — 본문과 그림 제목이 사실과 다르다

`src/connectivity.py` 의 SC는 68개 엣지를 손으로 적은 리스트이고, 출처는 논문 6편을
뭉뚱그려 파일 docstring에 적어둔 것이 전부다. **개별 값이 어느 논문의 어느 표에서
왔는지는 코드·문서 어디에도 없다.** 그런데 논문은 이것을 이렇게 부른다.

| 위치 | 표현 |
|---|---|
| `amari_gl_v7.html:125` (부제) | "**실측 dMRI 연결행렬**" |
| `amari_gl_v7.html:183` (방법) | "영역별 **실측 dMRI SC 행렬**" |
| `amari_gl_v7.html:823` (코드 주석) | "SC MATRIX (all values ≥ 0, **empirical dMRI**)" |
| `amari_gl_v7.html:1139` (그림 제목) | "SC 행렬 (**dMRI 실측**, 모두 ≥ 0)" |
| `amari_gl_v7.html:655` (한계) | "사용된 값들은 **선행 연구 평균 근사값**이다" |

같은 문서 안에서 부제·방법·그림 제목은 "실측"이라 하고 한계 절에서만 "근사값"이라고 한다.
이것은 방법론 논쟁 이전에 **표기 정합성 문제**이므로, 다른 모든 작업과 무관하게
**가장 먼저, 무조건 수정해야 한다.** (→ Phase 0)

### 0.4 ④의 이론적 함의 — β는 GSR의 동역학적 등가물이다

평가 의견은 "β가 반상관을 만들 수 있다"고 지적했다. 우리 자체 분석이 이를 더 강하게 뒷받침한다.

`PORTING_NOTES.md:86` 에서 야코비안 분석 결과 **β는 랭크-1 섭동이라 균일 모드만
이동시키고 λ_max 에 영향이 없다**는 것이 확인되었다. 즉 β 항은 **오직 전역(균일) 모드만
억제한다.** 이것이 바로 GSR(global signal regression)이 하는 일이다.

그리고 GSR은 음의 상관을 **수학적으로 강제한다**. 영역 시계열 xᵢ 에서 전역평균
g = (1/N)Σxᵢ 를 회귀 제거한 잔차 rᵢ 는 매 시점 Σᵢ rᵢ = 0 을 만족하므로

    0 = Var(Σᵢ rᵢ) = Σᵢ Var(rᵢ) + Σ_{i≠j} Cov(rᵢ, rⱼ)
    ⟹ Σ_{i≠j} Cov(rᵢ, rⱼ) = −Σᵢ Var(rᵢ) < 0

즉 GSR 후에는 음의 상관이 반드시 존재한다 (Murphy 2009; Saad 2012).

여기서 논문의 논증 구조에 순환 위험이 생긴다. 논문(`amari_gl_v7.html:287`)은
"β·⟨φ⟩ 는 GSR과 동등한 역할을 하므로 **GSR 적용 문헌값**이 비교 기준으로 적합하다"고
말한다. 그러면 **양쪽 모두 전역 모드가 제거된 상태**를 비교하는 것이고,
"반상관이 창발했다"는 결론은 상당 부분 비교 설계에서 이미 정해진다.

> **핵심**: "음의 구조연결 없이 반상관이 나온다"는 주장 자체는 여전히 의미가 있다.
> 다만 그것은 "**전역 억제 되먹임으로 반상관을 만들 수 있다**"는 주장이지,
> "**반상관이 아무 가정 없이 저절로 생긴다**"는 주장은 아니다. 논문의 현재 표현
> (`:689` "내인성 창발", "외부에서 부여받은 것이 아니라 자발적으로 발현")은 후자로 읽힌다.
> 전자로 정확히 좁혀 써야 한다.

### 0.5 ⑤의 통계적 함의 — r=0.922 는 블록 구조로 대부분 설명될 수 있다

`EMPR_FC`(`connectivity.py:121-140`)를 보면 DMN-TPN 블록 24개 성분이 전부
−0.16 ~ −0.32 의 좁은 범위에 있고, DMN 내부는 +0.28~+0.62, TPN 내부는 +0.28~+0.58 이다.
즉 이 행렬은 사실상 **네트워크 소속만으로 값이 거의 결정되는 블록 행렬**이다.

136쌍에 대한 Pearson r 은 이 경우 **블록 간 분산이 지배**한다. 따라서
"DMN 내부는 양, TPN 내부는 양, DMN-TPN은 음"이라는 세 가지만 맞추는 **어떤 모형이든**
높은 r 을 얻는다. 모델의 동역학이 기여한 부분을 분리하려면 **귀무모형 대비**가 필수다.
(→ Phase 3, 귀무모형 사다리)

## 1. 설계 원칙

재검증 전체를 관통하는 원칙은 두 가지다.

### 원칙 1 — 단일 파이프라인 (single-pipeline)

하나의 원자료에서, 같은 atlas·같은 공간·같은 전처리·같은 ROI 정의로 SC와 FC를
**모두 다시 계산**한다. 서로 다른 논문의 최종값을 조합하지 않는다.
가능하면 **같은 피험자**의 dMRI와 rs-fMRI를 쓴다. (평가 의견 ③의 요구)

### 원칙 2 — 전처리 대칭성 (preprocessing symmetry)

**시뮬레이션 BOLD에도 실측과 동일한 후처리를 적용한 뒤 비교한다.**

현재는 모델의 BOLD를 날것 그대로, GSR·밴드패스·nuisance 회귀를 거친 문헌값과 비교한다.
이것이 ④·⑤ 문제의 공통 뿌리다. 앞으로는 시뮬 BOLD를 실측과 같은 필터·같은 GSR 조건에
통과시킨 뒤 상관을 구한다. 이렇게 하면 "β vs GSR" 순환을 설계 단계에서 끊을 수 있다.

## 2. 증거 등급 분리 — Tier A / Tier B

17개 노드를 **같은 강도로 주장할 수 없다.** 분리해야 한다.

### Tier A — 피질 15노드 (DMN 6 + TPN 6 + SAL 3)

표준 파셀레이션(Schaefer, Glasser HCP-MMP1.0)에 모두 대응되고, 공개 커넥톰에
SC·FC가 일관된 파이프라인으로 이미 존재한다. **주 검증 대상.**

### Tier B — Claustrum 2노드 — 탐색적(exploratory)으로 강등 권고

전장(claustrum)은 아래 이유로 Tier A와 같은 근거 수준을 확보할 수 없다.

1. **표준 파셀레이션에 없다.** Schaefer·Glasser는 피질 전용이고, HCP CIFTI의
   피질하 19개 구조(시상·미상핵·조가비핵·창백핵·해마·편도체·측좌핵·간뇌·소뇌)에도
   전장은 **포함되지 않는다.** 즉 표준 dense connectome에서 전장 신호는 추출 자체가 안 된다.
2. **두께가 1–2 mm 다.** 2 mm 등방성 복셀에서 전장은 1복셀 두께이고, 양옆이
   섬피질(insula)과 조가비핵(putamen), 사이가 외포(external capsule) 백질이다.
   부분용적효과(partial volume)를 피할 수 없다.
3. **가장 중요한 검증쌍이 가장 취약하다.** L_CLA(−17, 8, 0)와 L_AI(−36, 12, 0)는
   **19.4 mm** 떨어져 있다. 반경 6 mm 구형 ROI에 6–8 mm 평활화를 적용하면 두 ROI의
   신호가 섞인다. 즉 검증표의 "CLA–AI 동측 = +0.45 ✓ 일치"는 **평활화에 의한
   신호 누출(signal leakage)만으로도 나올 수 있는 값**이다.

> **권고**: Tier B는 (a) 평활화 미적용, (b) 1.6 mm 이하 고해상도(HCP 7T 등),
> (c) 전용 전장 마스크(Berman 2020 자동분할 등), (d) **누출 대조군**
> (전장 마스크를 인접 백질/조가비핵으로 이동시킨 위약 ROI에서도 같은 상관이 나오는지)
> 을 모두 만족할 때만 정량 주장한다. 그 전까지는 "모델 확장 가능성 예시"로만 서술한다.

## 3. 검증 재설계

### 3.1 귀무모형 사다리 (null model ladder)

모델의 r 을 보고하기 전에, **더 단순한 설명이 같은 성능을 내지 않는지** 먼저 보인다.
각 귀무모형에 대해 동일한 136쌍 Pearson r 과 검증표를 계산한다.

| 코드 | 귀무모형 | 검증하는 질문 |
|---|---|---|
| N0 | 블록 평균만 (네트워크 소속으로 값 예측) | r 이 블록 구조만으로 얼마나 설명되나 |
| N1 | 유클리드 거리 감쇠 exp(−d/λ) | 공간 근접성만으로 얼마나 설명되나 |
| N2 | SC 자체 (SC 행렬 ↔ FC 상관) | 동역학 없이 구조만으로 얼마나 설명되나 |
| N3 | 차수 보존 재배선 SC로 돌린 모델 | SC의 **특정 배선**이 기여하나, 차수분포만 기여하나 |
| N4 | 선형 확산/OU 모형 (해석적) | GL 비선형항이 필요한가 (Messé 2014 논점) |

> **합격 기준**: Amari-GL 이 N0–N4 **전부를** 유의하게 상회해야 비선형 GL 동역학이
> 정당화된다. 특히 **N4를 못 이기면 σ·β 를 포함한 전체 이론 서술의 근거가 약해진다.**
> 이 결과는 불리하게 나와도 그대로 보고한다.

### 3.2 과적합 방지

- σ·β 를 맞춘 시드 집합과 평가 시드 집합을 분리한다 (이미 `PORTING_NOTES.md:116` 에서
  시드 42–45 / 900–907 로 시작한 방식을 공식화).
- 실측 FC도 **피험자를 반으로 나눠** 적합용 / 검증용으로 분리한다 (split-half).
- 보고 지표를 r 하나에서 **{r, 블록별 MAE, DMN-TPN 부호 일치율, 순위상관 ρ}** 로 확장한다.

### 3.3 β 절제 실험 (ablation) — 순환 없는 설계

원칙 2를 적용한 2×2 설계. 네 칸을 모두 보고한다.

| | 실측 FC: GSR 미적용 | 실측 FC: GSR 적용 |
|---|---|---|
| **모델 β=0** | (A) 기준선 | (B) 모델에만 GSR 없음 → 비교 부적절 |
| **모델 β>0** | (C) **핵심 검정** | (D) 현재 논문이 하고 있는 비교 |

- 추가로 **(E) 모델 β=0 + 시뮬 BOLD에 GSR 적용** 칸을 만든다.
  **(E)가 (D)와 비슷한 성능을 내면, β의 기여는 GSR로 대체 가능**하다는 뜻이고,
  "β에 의한 창발"이라는 서술은 약화된다. 이것이 이번 절제 실험의 실질적 판정 항목이다.
- 사전 예측을 문서에 먼저 적고 나서 돌린다 (사후 해석 방지).

## 4. 데이터 확보 경로 — 두 가지 선택지

평가 의견의 요구("같은 공개 원자료에서 SC와 FC를 일관된 파이프라인으로 재계산")를
만족시키는 방법은 두 가지이고, **비용 차이가 매우 크다.**

### 경로 1 (권장) — 이미 일관되게 처리된 공개 커넥톰 사용

전처리를 직접 돌리지 않고, **한 연구팀이 한 파이프라인으로 SC와 FC를 모두 산출해
공개한 데이터셋**을 쓴다. 평가 의견의 핵심 요구를 그대로 충족하면서 노트북에서 가능하다.

| 자원 | 내용 | 확보 방법 | 규모 |
|---|---|---|---|
| **ENIGMA Toolbox** (Larivière 2022) | HCP S1200 그룹평균 **SC + FC를 동일 파셀레이션**(Schaefer 100/200/400, Desikan)으로 제공 | `pip install enigmatoolbox` | 수십 MB |
| **Domhof et al. 2022** (EBRAINS) | HCP 200명 **개인별 SC + FC 쌍**, 다중 파셀레이션. 전뇌 모델링용으로 설계됨 | EBRAINS 계정 후 다운로드 | ~수 GB |
| **MICA-MICs** (Royer 2022) | 50명 SC+FC, micapipe 단일 파이프라인, 다중 스케일 | OSF/공개 | ~수 GB |

> **Domhof 2022 가 평가 의견 ③("같은 사람의 dMRI에서 구조연결을 만들고 그 사람의
> rs-fMRI와 비교")을 문자 그대로 충족한다.** 1순위 후보.

**현재 로컬에 이미 있는 자산** (`Macaque_Human_Homologs_M9_4mg8Z/S1200/`):
- Glasser HCP-MMP1.0 파셀레이션 dlabel (608 KB) ✅
- S1200 그룹평균 32k_fs_LR 표면 (MSMAll) ✅
- ⚠️ `Results/rfMRI_REST/*.dscalar.nii` 2개는 976 KB 씩으로 **그룹 PCA 전체 시리즈가
  아니라 단일 성분 맵 2장**이다. 이것으로는 dense connectome을 만들 수 없다.
  → 실측 FC는 위 표의 경로로 별도 확보해야 한다.

### 경로 2 (비권장) — 원자료부터 직접 전처리

OpenNeuro raw → fMRIPrep(기능) + QSIPrep(확산) → 파셀레이션 → FC/SC.

- **필요**: WSL2 + Docker Desktop, FreeSurfer 라이선스, 50–100 GB 이상, 피험자당 8–24시간
- **판단**: 의미 있는 N(≥ 30)을 이 노트북에서 처리하는 것은 **현실적으로 불가능**하다.
  클러스터/서버 접근이 확보되지 않으면 경로 2는 배제한다.
- 다만 **N=2–3 명만 시범 처리**해서 경로 1의 파셀 값과 대조하는 용도로는 의미가 있다(선택).

## 7. 사전에 합의해야 할 판정 기준

재분석은 **숫자가 나빠질 가능성이 높다.** 착수 전에 기준을 정해둔다.

- 실측 FC 대비 r 이 0.5–0.6 수준으로 떨어져도 그대로 보고한다.
- Amari-GL 이 귀무모형 N4(선형 모형)를 이기지 못하면, "GL 비선형 동역학이 필요하다"는
  주장을 철회하고 논문의 기여를 **"소산구조 관점의 이론적 재해석"**으로 재정의한다.
- (E) 조건이 (D)와 동등하면 "β에 의한 창발" 주장을 "전역 억제 모형과 GSR의 등가성"
  논의로 전환한다.

이 세 가지는 **실패가 아니라 결과**다. 미리 합의해두면 나중에 해석을 비틀 유인이 없어진다.

> **연구자 결정 (2026-09-21)**: ① Claustrum 은 **탐색적(Tier B)으로 강등**한다.
> ② 재분석으로 r 이 하락하는 상황을 **수용**한다. 위 세 항목이 발동해도 그대로 보고한다.

## 8. Phase 1 실행 결과 — 귀무모형 사다리 (2026-09-21)

`python scripts/run_nulls.py --ensemble 10 --rewire 5` 로 두 파라미터 집합에서 실행했다.
표적은 `EMPR_FC` 상삼각 136쌍이다.

| 코드 | 모형 | r (σ=0.985, β=0.45) | r (σ=1.25, β=0.80) | 표적에 적합 |
|---|---|---|---|---|
| — | **전체 Amari-GL** | **0.882** | **0.932** | — |
| N0 | 블록 평균만 | **0.966** | **0.966** | 예 |
| N1 | 거리 감쇠 (λ=47.7 mm) | 0.225 | 0.225 | 예 |
| N2 | SC 그 자체 | 0.752 | 0.752 | 아니오 |
| N3 | 가중치 치환 SC + Amari-GL | 0.234 (SD .063) | 0.270 (SD .052) | 아니오 |
| N4a | 선형 OU 해석해 | 0.894 | 0.936 | 아니오 |
| N4b | **선형 모형 + 동일 BW** | **0.884** | **0.935** | 아니오 |

### 8.1 결론 1 — r 지표 자체가 모형을 변별하지 못한다

**N0(블록 평균만) = 0.966 으로 전체 모델(0.882 / 0.932)보다 높다.**
동역학도 구조도 거리도 쓰지 않고 "이 노드가 DMN인가 TPN인가"만 아는 예측기가
전체 시뮬레이션을 능가한다.

N0 는 표적의 블록 평균을 그대로 쓰므로 귀무모형에 유리한 설정이다. 따라서 이것을
"모델이 나쁘다"로 읽어서는 안 된다. 정확한 함의는 **지표의 타당성 문제**다.

> `EMPR_FC` 에 대한 136쌍 Pearson r 은 블록 간 분산이 지배하므로,
> **어떤 모형이 더 나은지 변별할 수 없는 지표다.** r = 0.922 를 모델 성능의
> 근거로 제시할 수 없다. §3.2 의 다지표(블록별 MAE·부호 일치율·순위상관)로 교체해야 한다.

### 8.2 결론 2 — −φ³ 비선형항은 FC 패턴에 기여하지 않는다

**N4b(3차항만 제거, 나머지 전부 동일) 와 전체 모델의 차이가 Δ = −0.002 (σ=0.985),
Δ = −0.003 (σ=1.25) 으로 앙상블 변동폭(±0.02) 안에 있다.** N4b 는 표적에 적합되지
않은 공정한 대조이므로 이 비교는 그대로 유효하다.

임계점에서 멀기 때문일 가능성을 배제하기 위해 임계 근방(σ=1.25, λ_max=−0.131)에서도
확인했으나 결과는 동일했다. 즉 **BOLD rsFC 의 공간 패턴에 관한 한, 이 모델은
SC 그래프 위의 선형 확산 + 전역 억제 + BW 필터로 완전히 대체 가능하다.**

이것은 논문 §이론의 핵심 논증 — "σ 가 GL 분기점 근방이라 상관길이가 발산하고
그로부터 장거리 상관이 유지된다" — 을 **현재 지표로는 뒷받침할 수 없다**는 뜻이다.

> **다만 범위를 정확히 한정할 것.** 이 결과는 "비선형항이 **영상관(zero-lag FC)**에
> 기여하지 않는다"이지 "비선형항이 무의미하다"가 아니다. 임계성 주장을 유지하려면
> **선형 모형과 비선형 모형이 실제로 갈라지는 관측량**으로 옮겨가야 한다. 후보:
> 준안정성(metastability)·상태전이 통계, 눈사태 크기 분포(SOC), BOLD 진폭 분포의
> 비가우스성, 엔트로피 생성률(논문 `:707` 이 이미 후속 과제로 언급). **FC 하나로는
> 임계성을 논증할 수 없다.**

### 8.3 결론 3 — SC 배선 패턴은 실제로 기여한다 (긍정적 결과)

**N3(가중치 치환 SC) = 0.23–0.27 로 급락한다** (정상 SC 는 0.75–0.93).
엣지 위상과 총 결합강도를 보존한 채 가중치만 섞으면 성능이 무너진다.
즉 **"어느 영역쌍이 얼마나 강하게 연결되어 있는가"라는 구체적 배선 패턴이
FC 재현의 핵심 동력**이며, 이는 모델의 정당한 성과다.

또한 N2(SC 단독, 동역학 없음) = 0.752 에서 전체 모델 0.932 로의 개선은
**동역학+BW 가 기여한 실제 몫**이다. 다만 §8.2 에 따라 그 몫은 선형 동역학으로 충분하다.

### 8.4 종합 — 논문이 주장할 수 있는 것과 없는 것

| 주장 | 현재 근거로 가능한가 |
|---|---|
| SC 배선 패턴이 rsFC 공간 구조를 상당 부분 결정한다 | ✅ 가능 (N3 대비 명확) |
| 확산 동역학 + BW 가 SC 단독보다 FC 를 잘 설명한다 | ✅ 가능 (0.752 → 0.932) |
| 전역 억제만으로 음의 배선 없이 반상관이 생긴다 | △ 조건부 — §0.4 의 GSR 등가성 단서 필요 |
| GL **비선형성**이 FC 재현에 필요하다 | ❌ 불가 (N4b, 두 파라미터 집합 모두) |
| σ 가 임계 근방이라는 점이 FC 를 설명한다 | ❌ 불가 (같은 이유) |
| r = 0.922 가 모델의 정확도를 보여준다 | ❌ 불가 (N0 = 0.966) |

**권고**: 논문의 기여를 "비선형 임계 동역학이 DMN 을 재현한다"에서
**"소산구조 관점의 형식화 + SC 기반 확산 모형의 rsFC 설명력"**으로 재정의하고,
임계성 논증은 §8.2 의 대안 관측량으로 별도 검증한 뒤에 복원한다.
이는 §7 에서 사전 합의한 대응 방침 2·3 에 해당한다.
