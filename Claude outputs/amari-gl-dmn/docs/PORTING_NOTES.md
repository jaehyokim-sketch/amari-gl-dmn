# Python 포팅 검증 노트

> 작성: 2026-09-21 · Session 4 (VS Code 이관 작업)
> 대상: `amari_gl_v7.html` 내장 JavaScript → `src/` Python 패키지

원본 Artifact V7 의 시뮬레이션 코드를 numpy 로 포팅하면서 수행한 검증 기록이다.
포팅은 수식·상수·적분 방식·샘플링 타이밍까지 1:1 로 맞추었고
(`tests/test_port.py` 22개 통과), 그 과정에서 **논문 본문과 다시 맞춰봐야 할
지점 세 가지**가 드러났다. 아래는 그 근거와 재현 방법이다.

## 1. 포팅 충실도

| 항목 | 원본 JS | Python 포팅 | 일치 |
|------|---------|-------------|------|
| 적분 | Euler–Maruyama, DT=0.08 | 동일 | ✅ |
| φ 클리핑 | `[-4, 4]` | 동일 | ✅ |
| 결합항 | `Σⱼ Cᵢⱼ(φⱼ−φᵢ)` | `SC @ φ − φ·rowsum(SC)` (동치) | ✅ |
| 전역 억압 | `−β·mean(φ)·DT` | 동일 | ✅ |
| 잡음 | `noise·√DT·randn()` | 동일 | ✅ |
| BW 입력 | `max(0, φ·0.3) + 0.04` | 동일 | ✅ |
| BW 적분·클리핑 | f≥0.1, v≥0.05, q≥0.01 | 동일 | ✅ |
| 샘플링 | `sampleTimer ≥ 0.5` 누적 | 동일 → **실효 TR = 0.56s** | ✅ |
| warmup | 60s | 동일 | ✅ |
| 정밀도 | Float32 | Float64 | △ (무시 가능) |

`sampleTimer` 가 DT 단위로 누적되므로 실효 TR 은 0.5s 가 아니라
`ceil(0.5/0.08)×0.08 = 0.56s` 다. 원본과의 수치 일치를 위해 의도적으로
이 동작을 유지했다 (`tests/test_port.py::test_effective_tr_is_056`).

## 2. 재현된 값과 논문 보고값의 차이

### 2.1 문헌 FC 일치도 r

논문 V7 보고값은 **r = 0.922** 이나, 동일 파라미터(σ=0.985, β=0.45, noise=0.09)에서
Python 재현값은 다음과 같다.

| 조건 | r |
|------|---|
| 단일 실행, 800 샘플 | 0.806 ± 0.027 (8 시드) |
| 단일 실행, 1600 샘플 | 0.842 ± 0.020 |
| 단일 실행, 4000 샘플 | 0.875 ± 0.017 |
| 앙상블 30회 × 800 샘플 | 0.896 |
| 앙상블 10회 × 4000 샘플 | 0.897 |
| 앙상블, CLA 제외 15-노드 | 0.909 |

유한표본 잡음을 모두 제거해도 0.90 부근에서 수렴하며 0.922 에 닿지 않는다.
**논문의 r = 0.922 가 어떤 실행 조건(샘플 수·평균 방식·노드 집합)에서 나온
값인지 본문에 명시할 필요가 있다.** 재현:

```bash
python scripts/run_simulation.py --ensemble 30
```

### 2.2 DMN–TPN 반상관

논문의 핵심 주장은 "음의 구조적 결합 없이 −β⟨φ⟩ 만으로 반상관이 창발한다"이다.
**주장 자체는 성립하지만, β=0.45 에서는 크기가 문헌값에 크게 못 미친다.**

| β (σ=0.985 고정) | DMN–TPN 평균 FC | 문헌 |
|---|---|---|
| **0.45 (현재 v3)** | **−0.047** | −0.199 |
| 0.80 | −0.151 | |
| 1.20 | −0.197 ✅ | |
| 2.50 | −0.234 | |
| 10.0 | −0.245 (포화) | |

세션 연속성 기록의 "시뮬 −0.052" 와 일치하므로 이는 포팅 오류가 아니라
**원본 모델의 실제 거동**이다. β 를 약 2.7배 올리면 문헌값에 정확히 도달한다.

## 3. 핵심 발견 — 네트워크 임계점은 σ = 1 이 아니다

이것이 이번 포팅에서 나온 가장 중요한 결과다.

확산형 결합 `Σⱼ Cᵢⱼ(φⱼ−φᵢ)` 는 `−φᵢ·Σⱼ Cᵢⱼ` 라는 **추가 선형 감쇠**를 만든다.
따라서 노드 i 의 실효 선형계수는 `(σ−1)` 이 아니라 `(σ−1) − Σⱼ Cᵢⱼ` 이다.
SC 차수는 0.82(R_MTG)–1.75(PCC), 평균 1.24 이므로 임계점이 크게 이동한다.

야코비안 `J = SC − diag(k) + (σ−1)I − (β/N)·11ᵀ` 의 최대 실수고유값이 0 이 되는 지점:

> **σ\* = 1.3809** (β 와 무관 — β 항은 균일 모드만 이동시키는 랭크-1 섭동)

| σ | λ_max | 상태 |
|---|---|---|
| 0.985 (현재 v3) | **−0.396** | 임계점에서 한참 아래 |
| 1.25 | −0.131 | 임계 직하 |
| 1.30 | −0.081 | 임계 직하 |
| 1.3809 | 0.000 | **임계점** |
| 1.50 | +0.119 | 초임계 (붕괴) |

즉 논문이 σ=0.985 를 "임계 직하(subcritical, 임계점 바로 아래)"로 서술한 것은
**단일 노드 기준**으로는 맞지만 **네트워크 기준으로는 성립하지 않는다.**

### 3.1 그리고 실제 최적점은 임계 직하에 있다

σ 를 올리며 문헌 일치도를 측정하면 임계점 바로 아래에서 정점을 찍고
초임계에서 붕괴한다 — 논문의 임계성·SOC 논증이 **오히려 더 잘 뒷받침된다.**

| σ (β=0.80) | λ_max | r | DMN–TPN | 검증 통과 |
|---|---|---|---|---|
| 0.985 | −0.396 | 0.901 | −0.149 | 5/7 |
| 1.20 | −0.181 | 0.930 | −0.237 | **7/7** |
| 1.30 | −0.081 | **0.942** | −0.331 | **7/7** |
| 1.35 | −0.031 | 0.942 | −0.409 | 4/7 (반상관 과다) |
| 1.3809 | 0.000 | 0.937 | −0.463 | 2/7 |
| 1.50 | +0.119 | 0.796 | −0.110 | 3/7 |
| 1.60 | +0.219 | 0.719 | −0.018 | 4/7 |

### 3.2 권장 파라미터

시드 42–45(적합)와 900–907(검증)의 두 독립 집합에서 모두 안정적인 조합:

| 파라미터 | r (적합) | r (검증) | DMN–TPN | 통과 |
|---|---|---|---|---|
| σ=0.985, β=0.45 (현재) | 0.904 | — | −0.047 | 5/7 |
| **σ=1.25, β=0.80** | 0.937 | **0.931** | −0.270 | **7/7 · 7/7** |
| σ=1.30, β=0.80 | 0.942 | 0.936 | −0.326 | 7/7 · 7/7 |
| σ=1.20, β=0.60 | 0.933 | 0.924 | −0.166 | 7/7 · 7/7 |

**σ = 1.25, β = 0.80** 을 권장한다. 문헌 일치도가 보고값 0.922 를 넘고,
7개 검증 항목을 모두 통과하며, λ_max = −0.131 로 여전히 명확한 임계 직하다.
재현:

```bash
python scripts/run_simulation.py --sigma 1.25 --beta 0.80 --ensemble 10
python scripts/param_sweep.py --sigma 0.95 1.45 11 --beta 0.3 1.3 11 --ensemble 3
```

> ⚠️ 이 결과는 **Python 포팅 기준**이다. 논문 파라미터를 고치기 전에
> 원본 JS Artifact 에서 σ·β 슬라이더를 같은 값으로 두고 교차확인할 것.
> 동역학은 검증되었으나 σ 를 바꾸면 논문 본문의 분기 이론 서술
> (§이론, §논의의 "임계 직하" 표현)도 함께 수정해야 한다.

## 4. 확인된 설계 건전성

포팅 과정에서 아래 항목은 문제없이 재현되었다.

* SC 전 성분 비음수 — 반상관이 입력이 아닌 **결과**임이 코드 수준에서 보장됨
  (`test_sc_is_nonnegative`, `test_dmn_tpn_structural_links_are_positive`).
* V7 의 CLA 파라미터 하향(0.35 → 0.30)이 세 위치 모두 반영됨 (`test_v7_cla_values`).
* CLA–AI 동측 결합 +0.45 재현 (시뮬 +0.45–0.49, 허용 [0.35, 0.55]) — macaque
  BALSA 검증과 일관.
* DMN 내부 +0.43 (문헌 +0.443), TPN 내부 +0.38 (문헌 +0.425) — 블록 구조 재현 양호.
* BW 정상상태에서 BOLD = 0, 상태변수 하한 유지, 발산 없음.

가장 큰 잔차는 SAL 내부(시뮬 +0.38 vs 문헌 +0.58)와 DMN–TPN 블록이다.
