## 1. DeepSeek API 헬퍼

### 결론: Claude Code 모델 선택 메뉴에 DeepSeek 추가는 불가능

`/model` 커맨드와 VS Code 모델 드롭다운은 Anthropic Claude 계열만 지원한다.
`ANTHROPIC_BASE_URL` 로 프록시 우회는 기술적으로 가능하나 Anthropic 공식 문서가
"non-Claude 모델 라우팅은 지원하지 않는다"고 명시하며, tool use·vision 등 핵심 기능이
깨진다. → **별도 CLI 스크립트 방식으로 결정.**

### 산출물

| 파일 | 내용 |
|---|---|
| `scripts/deepseek_helper.py` | DeepSeek REST API(OpenAI 호환) CLI. SDK 불필요, `requests` 만 사용 |
| `.env` | `DEEPSEEK_API_KEY`, `DEEPSEEK_MODEL=deepseek-flash` (**gitignore 됨**) |
| `.env.example` | 플레이스홀더 버전 |
| `.gitignore` | 신규 생성, `.env` 제외 |
| `CLAUDE.md` (루트) | "DeepSeek한테 ~시켜줘" 요청 시 자동 위임하는 규칙 |

### 사용법

```
python scripts/deepseek_helper.py ask "질문"
python scripts/deepseek_helper.py summarize "파일.pdf" --lang ko
python scripts/deepseek_helper.py translate "파일.md" --to en --out 결과.md
python scripts/deepseek_helper.py analyze "파일" --question "질문"
python scripts/deepseek_helper.py chat        # 대화형, /exit 로 종료
```

### 주의사항

* 실제 API 모델명은 **`deepseek-flash`** 와 `deepseek-v4-pro` 둘뿐이다.
  요청했던 `deepseek-v4.1-flash` 는 400 오류가 난다.
* 작업 중 `.env.example` 과 `.env - 복사본.example` 에 **실제 API 키가 노출**되어
  `.env`(gitignore 대상)로 옮기고 복사본은 삭제했다. 키는 커밋되지 않았다.
* Windows 콘솔 한글 깨짐은 스크립트에서 UTF-8 강제로 해결했다.

## 3. 외부 평가 반영 — 재검증 (이번 세션의 핵심)

### 3.1 받은 평가 의견 요지 (5개)

① OpenNeuro 좌표계 불일치 ② raw BOLD 전처리 부재 ③ SC 출처 혼재(실측 vs 문헌근사)
④ β=0.45 가 반상관을 만든 것 아닌가 ⑤ r=0.922 를 실측 검증으로 해석하는 문제

### 3.2 코드 대조 결과 — 5개 모두 사실, 2개는 지적보다 심각

* **①이 더 심각**: `세션기록_Session2.md` 에 "130명 중 **sform_code=1 제약으로** 13명".
  `sform_code=1` = `NIFTI_XFORM_SCANNER_ANAT` = **MNI 아님**(MNI면 4). 즉 그 필터는
  **MNI 정합이 안 된 피험자만 골라내는 필터**였다. r=0.188 은 해석 불가능한 값이다.
* **③이 더 심각**: `src/connectivity.py:36-95` 전체가 손으로 입력한 상수 리스트인데,
  논문은 부제·방법·**그림 제목**·코드 주석 4곳에서 "실측 dMRI"라 부르고 한계 절에서만
  "문헌 근사값"이라 한다. 표기 정합성 문제.

### 3.3 추가로 발견한 두 가지

* **β 는 GSR 의 동역학적 등가물이다.** `PORTING_NOTES §3` 에서 이미 "β 는 랭크-1
  섭동이라 균일 모드만 이동"임을 밝혔는데, 이는 β 가 전역 모드만 억제한다는 뜻이다.
  GSR 후 잔차는 Σᵢrᵢ=0 이므로 Σ_{i≠j}Cov = −ΣVar < 0, 즉 **음의 상관이 수학적으로
  강제**된다(Murphy 2009; Saad 2012). "β⟨φ⟩ 는 GSR 과 동등하므로 GSR 문헌값과
  비교한다"는 논문 논리는 양쪽 모두 전역모드를 제거한 순환 비교가 된다.
* **r=0.922 는 블록 구조로 부풀려진다.** `EMPR_FC` 의 DMN-TPN 24개 성분이 전부
  −0.16~−0.32 인 사실상 블록 행렬이라, 블록 3개만 맞추면 어떤 모형이든 높은 r 을 얻는다.

### 3.4 연구자 결정 (2026-09-21)

1. **Claustrum 은 탐색적(Tier B)으로 강등**한다.
2. **재분석으로 r 이 하락하는 상황을 수용**한다.

### 3.6 Phase 1 완료 — 귀무모형 사다리

신규: `src/nulls.py`, `scripts/run_nulls.py`
(`src/simulate.py` 에 `step_fn` 주입점 추가 — 기본 동작 불변, r=0.8347 회귀 확인)

| 모형 | σ=0.985 | σ=1.25 |
|---|---|---|
| **전체 Amari-GL** | 0.882 | 0.932 |
| N0 블록 평균만 | **0.966** | **0.966** |
| N1 거리 감쇠 | 0.225 | 0.225 |
| N2 SC 단독 | 0.752 | 0.752 |
| N3 가중치 치환 SC | 0.234 | 0.270 |
| N4a 선형 OU 해석해 | 0.894 | 0.936 |
| N4b **선형(−φ³ 제거)** | **0.884** | **0.935** |

**결론 3가지**

1. **r=0.922 는 모형 변별력이 없다** — N0(네트워크 소속만 아는 예측기)가 0.966 으로
   전체 모델을 능가. 지표 타당성 문제이지 "모델이 나쁘다"가 아니다.
2. **−φ³ 비선형항은 FC 에 기여하지 않는다** — N4b 와 Δ = −0.002/−0.003.
   임계 근방(σ=1.25)에서도 동일. **rsFC 만으로 임계성 논증 불가.**
   유지하려면 준안정성·눈사태 분포·엔트로피 생성률 등 선형/비선형이 갈라지는 관측량 필요.
3. **SC 배선 패턴은 실제로 기여한다 (긍정적)** — 가중치 치환 시 0.75 → 0.23 급락.

→ 논문 기여를 "비선형 임계 동역학이 DMN 을 재현한다" 에서
**"소산구조 관점의 형식화 + SC 기반 확산 모형의 rsFC 설명력"** 으로 재정의 권고.
